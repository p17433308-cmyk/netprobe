# Contributing to NetProbe

Thanks for your interest in NetProbe! We welcome contributions from the security research community.

## How to Contribute

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/my-feature`)
3. **Commit** your changes (`git commit -m 'Add my feature'`)
4. **Push** to the branch (`git push origin feature/my-feature`)
5. **Open** a Pull Request

## Areas We Need Help

- **Protocol grammars** — add grammar definitions for protocols we don't cover yet
- **Tool harnesses** — add support for new network analysis tools
- **Mutation strategies** — novel fuzzing techniques
- **Bug reports** — found a bug? Open an issue with reproduction steps

## Responsible Disclosure

If you discover a vulnerability in a network tool using NetProbe, please follow responsible disclosure:

1. Report to the tool's security team first
2. Wait for a patch before public disclosure
3. Credit the tool maintainers in any write-up

## Code Style

- Python 3.10+
- Type hints encouraged
- Run `pytest` before submitting
