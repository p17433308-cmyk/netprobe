# Security Policy

## Responsible Disclosure

NetProbe is a security research tool. If you use it to discover vulnerabilities in network analysis tools, **please follow responsible disclosure practices**:

1. Report findings to the affected tool's security team
2. Allow reasonable time for patching (typically 90 days)
3. Do not publish exploit code before a fix is available

## Tool-Specific Contacts

| Tool | Security Contact |
|------|-----------------|
| Wireshark | security@wireshark.org |
| Suricata | security@openinfosecfoundation.org |
| tcpdump | security@tcpdump.org |
| Zeek | security@zeek.org |
| Snort | security@snort.org |

## Reporting Issues in NetProbe

If you find a security issue in NetProbe itself, please open a GitHub issue or contact the maintainers directly.
